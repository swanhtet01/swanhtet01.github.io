# Synthetic Shop photo catalog

These five product photos are used only by the native Shop Flutter visual-capture
fixture. They are generic grocery examples; no branded package is represented.
The names are localized into separate English and Burmese captures. Prices,
sale amounts, and opening stock are **illustrative test values**, not current
Myanmar retail prices, stock, or a live catalog. A Burmese copy review is still
needed before these examples become customer-facing marketing material.

The adjacent ledger.json records each original Wikimedia Commons file page,
direct source, author, reuse terms, original JPEG SHA-1/SHA-256, and the committed
PNG derivative SHA-256. On 2026-10-22 the original bytes were checked against
the Commons SHA-1 where Commons publishes it; for the red onion, the SHA-1 and
SHA-256 were computed from the linked original. The linked file pages establish
CC0 or author public-domain dedication. Source JPEGs are not committed.

Each image was fitted, without cropping, inside a white 192 x 192 RGB canvas.
Only the PNG IHDR, IDAT, and IEND chunks remain; no JPEG EXIF, GPS, or PNG
ancillary metadata is present. Each file is below the Shop local thumbnail
limit. The always-on fixture test verifies the committed hashes, thumbnail
validity, and chunk types; the optional Flutter capture CI renders English and
Burmese screens at 320, 390, 820, and 1200 px.

These are synthetic Flutter-rendered review images. They do not prove installed
Android, iPad, Windows, printer, scanner, or customer acceptance.
