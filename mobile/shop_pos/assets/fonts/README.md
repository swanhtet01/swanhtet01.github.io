# Bundled Shop fonts

The offline Shop app bundles Inter for English and Noto Sans Myanmar for Burmese. Both files were fetched from the official [Google Fonts repository](https://github.com/google/fonts) at commit `45e3d5269e4a17d823f6d84470bc084dc5ae46f6` on 21 October 2026. The accompanying `OFL.txt` files are the original SIL Open Font License notices and must ship with any redistributed source or app package as required by their terms.

The font choices and license do not establish that every label fits on every device. Compact English and Burmese checkout still require widget and real-device review.
