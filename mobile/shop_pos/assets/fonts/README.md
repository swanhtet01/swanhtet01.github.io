# Bundled Shop fonts

The offline Shop app bundles Inter for English and Noto Sans Myanmar for Burmese. The original variable files were fetched from the official [Google Fonts repository](https://github.com/google/fonts) at commit `45e3d5269e4a17d823f6d84470bc084dc5ae46f6` on 21 October 2026. The app also bundles the compact Noto Sans Myanmar UI cut from [Noto Fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSansMyanmarUI) at commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`, with the full Myanmar font as a glyph fallback. The accompanying `OFL.txt` files are SIL Open Font License notices and must ship with redistributed source or app packages as required by their terms.
