# >_ SuperMega brand system

Version: `jade-v2-2026-07`

SuperMega should feel like a premium operating instrument: focused, calm, exact, and accountable. The `>_` mark is both the logo and the product promise—work enters, evidence is processed, and a responsible person decides what happens next.

## Identity

- Name: **SuperMega**
- Public domain: `supermega.dev`
- Product domain: `app.supermega.dev`
- Signature: `>_`
- Positioning: **Operating software for Myanmar companies.**
- Portfolio: **Shop**, **Plant**, **Website**, and **Ecommerce**

Do not create separate visual identities for products, templates, demos, agents, or internal tools. They inherit this system.

## Core palette

| Token | Value | Use |
| --- | --- | --- |
| Background | `#f6f4ee` | Primary canvas |
| Raised background | `#eef2ec` | Section rhythm and gradient base |

| Soft panel | `#eef4ef` | Quiet grouped surfaces |

| Muted | `#56665d` | Supporting text |
| Quiet | `#5f6c64` | Metadata |
| Line | `rgba(31, 68, 51, .12)` | Borders (`rgba(31, 68, 51, .2)` for strong) |
| Accent | `#0b745e` | Product action, link, active state, verified, evidence-ready |
| Accent strong | `#075c4b` | Hover and pressed emphasis |
| Accent soft | `rgba(11, 116, 94, .1)` | Selected and highlighted fills |

Use the warm paper canvas, restrained jade accents, thin low-contrast borders, soft shadows, and generous space. No alternate dark, neon-rainbow, or client-branded themes on canonical pages.

## Typography and mark

- Interface text: Geist or Inter over the system sans stack; compact, readable, and neutral.
- Operational labels and metadata: `SFMono-Regular`, Consolas, or equivalent monospace.
- Headlines: sans, high contrast through size and spacing rather than decorative type.
- Mark: light rounded terminal tile, jade chevron, ink underscore.

## Voice

- Lead with the operational outcome.
- Use short, concrete sentences.
- Name evidence, owner, state, and next action.
- Distinguish demo, trial candidate, and activated managed trial.
- Say “not yet verified” when evidence is missing.
- Avoid hype, invented metrics, guaranteed outcomes, and unsupported enterprise claims.

## Interface rules

1. Every page uses the same mark, palette, shell rhythm, button treatment, focus state, and status language.
2. Shop, Plant, Website, and Ecommerce differ by workflow and data—not by brand.
3. AI output is visibly a draft, recommendation, or brief until a person accepts it.
4. Warning and danger colors always describe a real state; they are never decoration.
5. Mobile layouts preserve the work hierarchy and never hide required controls.
6. Public pages prove the product without pretending sample data is a live customer system.

## Release checklist

- Correct `jade-v2-2026-07` metadata and `>_` favicon.
- Shop, Plant, Website, and Ecommerce are the four customer products.
- Public and app routes use the same language and design tokens.
- No retired names, stale client marks, broken encoding, placeholder copy, or unsupported claims.
- Keyboard focus, reduced motion, readable contrast, responsive layout, and exact release metadata pass verification.
