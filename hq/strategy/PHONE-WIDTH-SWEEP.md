## Why this exists

P3.10 was found by accident: the Plant journey noticed that a verifier-pinned phone rule
hid the "Start here" status notice with `display: none`, which also removed it from the
accessibility tree, so a phone operator never saw "shift close completed" or the reason a
write was blocked. That defect class — a phone rule quietly discarding load-bearing text —
is invisible to a string-pinning verifier and to a journey that reads the DOM. Only
computed style and geometry on the built app show it. This sweep measures that class
everywhere the four journeys go, so the next one is found on purpose.
